# Dressmaker · Mod 多言語アシスタント

[简体中文](README.zh-CN.md) · [English](README.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Español](README.es.md)

Yuuma ModLoader の画面と Mod の英語表示を翻訳する、独立した macOS ツールです。**0.1.5 は初期版で、ゲーム内での動作は未検証です。**

## 機能

- ゲームの翻訳先とアシスタント画面を別々に設定。中国語・英語・日本語・韓国語・フランス語・ドイツ語・スペイン語に対応。
- 辞書、手動修正、キャッシュはオフラインで使用可能。未知の文章には任意の Argos モデルを利用。
- キー不要の MyMemory、試験的な Bing Web 連携、利用可能な LibreTranslate インスタンスを選択。
- 新しい Mod の一般的な JSON 表示項目をスキャンし、ゲーム内の未知の英語も収集。
- 対象言語ごとに翻訳を保存し、手動修正を優先。変数とリッチテキストタグを保護。

## プレイヤー向け

1. [Yuuma ModLoader の Mac 版](https://www.nexusmods.com/dressmaker/mods/1?tab=files)を先に導入します。
2. リポジトリの Releases から **Dressmaker-Languages-Mac-0.1.5.zip** を取得し、フォルダ全体を展開します。Python 3.9 以降が必要です。
3. `Start.command` または `针影裁梦多语言助手.app` を開きます。
4. 画面の言語、ゲームフォルダ、翻訳先を確認し、設定を保存してパッチを導入し、ゲームを再起動します。
5. 新しい Mod を導入したらスキャンし、翻訳中はアシスタントを開いたままにします。結果は手動で修正できます。

詳しい操作、モデル、削除方法は[日本語の説明書](docs/ja.md)へ。GitHub の Download ZIP はソースであり、コンパイル済みプラグインと `.app` は含みません。プレイヤーは Release の配布版を使ってください。

## 対応範囲と検証

`name`、`displayName`、`display_name`、`description`、`tooltip`、`title` などの JSON 項目を読み取ります。実行時は ModLoader の Unity Text / TextMeshPro と、スキャンで見つかった名前を対象にします。独自画面、画像文字、特殊なバイナリ形式、英語以外の原文には対応を保証しません。布地の追加やゲーム本体の完全な新規翻訳は行いません。

ModLoader 0.7.3 / BepInEx 5.4.23.5 / Unity 6000.3.4f1 に対してビルドし、63件の自動テストを通過しました。ローカル画面の言語切り替えを確認し、Bing と MyMemory から実際の翻訳を取得しました。Web 連携はネットワーク、制限、ページ変更で失敗する場合があります。第三者の布地名、ゲーム内の配置とフォントは未検証です。

オンラインでは未翻訳の英語表示を選択したサービスに送ります。間隔は最低3秒、既定の1日上限は UTF-8 で4,500バイトです。失敗時は原文を保持します。MyMemory への代替は既定で無効で、有効時は両方の試行を上限に計上します。辞書と既存キャッシュはオフラインで使えます。

## 開発と貢献

ソースは `src/` と `assistant/`。基本機能は Python 標準ライブラリのみを使います。

```sh
python3 -m unittest discover -s tests -v
```

プラグインのビルドには、自分のゲームと ModLoader のアセンブリ、.NET SDK が必要です。アシスタントは0.1.5で、変更していないゲームプラグインの内部版は0.1.0です。GitHub Actions の自動チェックが有効です。結果はリポジトリの Actions ページで確認できます。

用語、フォント、互換性の Issue / Pull Request を歓迎します。ゲーム、OS、ModLoader の版と公開できる原文例を添えてください。画面文言を変える場合は7言語の辞書と説明書を更新し、セーブ、非公開の Mod、ゲーム素材を投稿しないでください。

## 手動インストール用ZIPをダウンロード

保存済みのゲーム言語のプラグイン、辞書、訳文を出力します。ゲームフォルダーへの書き込みは不要です。訳文や言語を変えたら再出力してください。ZIPには7言語の手順書があります。 [手動インストール用ZIPをダウンロード](docs/manual-ja.md).


## 翻訳の進行状況

毎秒更新します。進捗は処理件数を表します。原文維持と失敗は翻訳成功に含みません。未保存の編集を保持しながら一覧を自動更新します。

## Google Webと訳文の保存

GoogleへのWebリクエストはキー不要です。接続環境、ページ変更、利用制限により失敗する場合があります。リクエストの間隔は3秒以上です。

例：今日（UTC）：4,498 / 4,500 バイト使用・残り 2 バイト。これはローカル予算で、増やしてもサービスの上限は増えません。

訳文はローカルに保存され、オフラインでも再利用できます。更新時は data フォルダーを残してください。言語別キャッシュと手動修正は保持されます。

## 辞書の検索と絞り込み（0.1.4）

検索は原文と保存済み訳文の両方を対象にします。入力すると自動更新され、Enterでも検索できます。収集済みテキストと現在の翻訳先言語の辞書・キャッシュを統合し、同じ原文は1行にまとめます。

- **状態**：未翻訳、翻訳済み、原文を保持。未翻訳件数は実際に使用する保存済みの値に基づき、未保存の変更は翻訳済みに数えません。
- **方法**：辞書、用語の組み合わせ、手動修正、オフラインモデル、Google、Bing、MyMemory、LibreTranslate。古い機械翻訳が辞書で上書きされている場合は辞書と表示します。
- **取得元**：全項目、収集済み、ゲーム表示、Mod内容、管理ツール候補、辞書・キャッシュのみ。表示された未翻訳を探すには「未翻訳」＋「ゲーム表示テキスト」を選択します。
- **並べ替えとページ**：原文の昇順・降順、最近保存した順、ゲーム表示優先。1ページ25・50・100件、ページ番号で直接移動できます。一致しない場合は説明が表示され、絞り込みを解除できます。

絞り込みとページ移動では未保存の変更を保持し、件数を表示します。各行を保存してからページを閉じるか再読み込みしてください。再読み込みすると未保存の下書きは失われます。保存した行は絞り込み結果から消えることがあります。検索・絞り込みは翻訳サービスに接続せず、翻訳予算も使いません。

絞り込みは一覧のみに適用されます。「未翻訳テキストを翻訳」は収集済みのキューを処理します。

未翻訳件数はゲーム表示文字、Mod内容、管理ツール候補、辞書/キャッシュのみを分けて表示します。プログラムから内部形式、エラー、未使用文字列が収集されることがあり、候補件数は画面の翻訳漏れ件数ではありません。自動翻訳は表示文字とMod内容のみ処理します。「未翻訳」＋「ゲーム表示テキスト」で収集済みの表示文字を確認できます。未訪問の画面はゲームで開いて収集してください。

サービス失敗時は一時停止し、残りを未処理として保持します。待機終了後、同じ言語と範囲で未完了の処理を再試行し、手動開始した候補も対象になります。再度クリックしても待機は解除されず、進捗もリセットされません。設定変更は古い再試行を取り消します。正常に保存した訳文だけが未翻訳件数を減らします。
