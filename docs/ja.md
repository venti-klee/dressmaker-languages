# Dressmaker 多言語アシスタント 0.1.2

[简体中文](zh-CN.md) · [English](en.md) · **日本語** · [한국어](ko.md) · [Français](fr.md) · [Deutsch](de.md) · [Español](es.md)

Yuuma ModLoader の画面と Mod アイテムの表示名を翻訳する、独立開発の Mac 用アシスタントとゲームパッチです。[SallyHCA のツール](https://www.nexusmods.com/dressmaker/mods/339)と[公開プロジェクト](https://github.com/Sally-4869/dressmaker-mods-cn)の機能説明を参考にしています。そのコード、辞書、素材は同梱していません。

GitHub の Download ZIP はソースのみで、ビルド済みプラグインと `.app` はありません。プレイヤーは Mac Release を利用し、ソース利用者は下記の手順でビルドしてください。公開手順は [README](../README.ja.md) にあります。

## 導入手順

1. 先に [Yuuma ModLoader の Mac 版](https://www.nexusmods.com/dressmaker/mods/1?tab=files)を導入してください。本パッチはこの PC の 0.7.3 を参照してコンパイルしています。
2. パッケージ全体を書き込み可能なフォルダーに展開します。Python 3.9 以降が必要です。基本機能には追加の Python ライブラリや .NET ランタイムは不要です。
3. `Start.command` または `针影裁梦多语言助手.app` をダブルクリックすると、ローカルのブラウザ画面が開きます。利用中はコマンドウィンドウを閉じないでください。
4. ページ上部の「アシスタントの表示言語」を選びます。画面の文言と説明書のリンクがすぐに切り替わり、このブラウザに保存されます。ゲームの翻訳先は変わりません。初回はブラウザの言語を使用し、未対応の場合は英語になります。
5. ゲームフォルダーと「ゲームの翻訳先言語」を確認し、「設定を保存」を押します。ゲームの初期翻訳先は簡体字中国語です。
6. 「ゲームパッチをインストール／更新」を押します。専用の `BepInEx/plugins/DressmakerLanguages/` と `BepInEx/config/DressmakerLanguages/` だけを作成・更新します。
7. 進行状況を保存してゲームを通常の方法で再起動し、Mod Manager / Mod Settings で表示を確認します。以後の辞書・言語変更は、収集済みの文字に通常約 2 秒で反映されます。
8. 新しい Mod を導入したら「Mod とマネージャーをスキャン」を押してください。ゲーム画面に表示された未翻訳の英語も自動収集されます。

手動導入の場合は同梱の `BepInEx/plugins/DressmakerLanguages/` をゲームの同じ場所にコピーし、アシスタントの導入ボタンで設定を生成してください。Windows の `.exe` アシスタントや Vortex は不要です。

## 対応言語と範囲

アシスタント画面と Markdown 説明書は、中国語・英語・日本語・韓国語・フランス語・ドイツ語・スペイン語に対応します。画面言語とゲームの翻訳先は独立しています。

ゲーム用の共通用語は中国語・日本語・韓国語・フランス語が各 148 件、ドイツ語・スペイン語が各 14 件です。中国語と日本語には、自分のゲームにある公式翻訳表も取り込みます。この PC の中国語辞書は合計 5,157 件でしたが、ゲームの版によって変わります。公式翻訳はローカルで生成し、配布 ZIP には含めません。英語を選ぶと原文に戻ります。

キャッシュは翻訳先ごとに分かれています。対象は Mod の表示テキストであり、ゲーム本体に韓国語やフランス語などの完全な翻訳を追加するものではありません。

## オフラインとオンライン

手動修正を最優先し、その他は **辞書 → キャッシュ → 全単語を認識できる用語の組み合わせ → 導入済み Argos オフラインモデル → 無料オンラインサービス** の順に処理します。

辞書と保存済みの翻訳は導入直後からオフラインで使えます。用語を組み合わせる場合は全単語が既知である必要があります。モデルもネット接続もない未知の文章は、英語のまま翻訳待ち一覧に残ります。

未知の文章もオフラインで訳すには、翻訳先を選んで「この言語のオフラインモデルをダウンロード」を押します。初回は独立した Python 環境とモデルをダウンロードするためネット接続が必要で、時間がかかる場合があります。完了したらアシスタントを終了して開き直し、オンライン翻訳を無効にして設定を保存してください。モデルは言語ごとに導入が必要で、現在の Argos モデル一覧によって提供状況が変わります。モデルは同梱しておらず、導入フロー全体はまだ実機検証していません。

標準のオンラインサービスは API キー不要の MyMemory 公開 API です。サービス側の上限に加え、本ツールは 1 日 4,500 UTF-8 バイトの上限、送信間隔、失敗時の待機時間を設定します。1 回の無料リクエストは最大 500 バイトです。長い文章にはオフラインモデルか手動翻訳を使ってください。利用できる LibreTranslate HTTPS インスタンスを指定することもできますが、無料利用や継続的な提供は保証しません。

オンライン時はローカル訳がない英語の表示テキストだけを選択したサービスへ送り、セーブデータや Mod パッケージは送りません。成功した訳を保存し、通信失敗・上限到達・不正な応答の場合は原文を残します。なりすまし、課金や CAPTCHA の回避機能はありません。

## 無料翻訳サービス

翻訳サービスを選び、**設定を保存**してください。

- **MyMemory**：既定の公開API。キーは不要ですが、サービス側の利用制限があります。
- **Bing Web連携（試験的）**：キー不要。公開翻訳ページから一時的なセッションを取得し、そのセッションで翻訳を要求します。安定した公式開発者APIではなく、ページやセッションの仕組み、利用制限の変更で動かなくなる場合があります。
- **LibreTranslate**：利用できるHTTPSインスタンスを入力します。料金やアカウント要件はインスタンスによって異なります。現在はキー不要のインスタンスに対応しています。

選択したサービスが利用できない場合にMyMemoryを使う設定は、既定では無効です。ネットワークまたはサービスの障害時に一度だけ代替を試します。上限超過、長すぎる文章、書式の破損、空のURLでは代替を使いません。同じ文章が2つのサービスに送られる場合があり、両方の試行を1日の予算に計上します。リクエスト間隔は最低3秒です。失敗が続く場合は5分間待機し、原文を保持します。辞書とキャッシュはオフラインで使えます。

Bingのセッションはメモリ内だけに保持します。ログイン、アカウント保存、プロキシの切り替え、CAPTCHAの回避は行いません。成功した翻訳はゲームの対象言語ごとに保存し、手動修正を優先します。

セッション解析、中国語コード、異常応答、オフラインキャッシュ、代替処理、予算を含む36件の自動テストを通過しました。Bingから中国語・日本語・韓国語・フランス語・ドイツ語・スペイン語の実際の翻訳を取得し、キャッシュのオフライン再利用と `{0}` の保持を確認しました。接続エラーやタイムアウトもあったため、試験的な機能のままです。

## 翻訳の修正と削除

英語の原文を検索し、翻訳を編集して「保存」を押してください。手動修正は同じ言語の機械翻訳と辞書より優先されます。変数・改行・リッチテキストのタグを保ってください。壊れた書式の訳は保存しません。表示言語を変えても、編集中の訳は保持されます。

一覧は最大 500 件です。他の項目は検索してください。「未翻訳テキストを翻訳」はマネージャーの候補文字列も処理します。自動モードは実際に表示された文字と Mod 内容を優先し、未使用のプログラム文字列に無料上限を消費しません。

「パッチをアンインストール」を押し、ゲームを再起動します。専用プラグインと設定は `data/backups/` に移動し、翻訳データは残ります。元のローダー・Mod・アイテム ID・画像・セーブデータは本パッチで変更しません。

## 保存先

- `data/translations.sqlite3`：言語別キャッシュと手動修正。
- `data/settings.json`：翻訳先、オンライン設定、ゲームのパス。
- `data/model-install.log`：オフラインモデルの導入ログ。
- `.venv/` と `models/`：モデル環境とモデル。
- ゲームの `BepInEx/config/DressmakerLanguages/pending.jsonl`：収集した未知の文字。
- ゲームの `BepInEx/LogOutput.log`：`Dressmaker Languages` を検索し、読み込みやフォントの問題を確認します。

画面はローカル PC にだけ接続し、書き込み操作はランダムなセッショントークンで保護します。終了後も公開済み辞書とキャッシュはゲーム内で使えます。自動補訳にはアシスタントの起動が必要です。

## 検証状況と制限

ModLoader 0.7.3 / BepInEx 5.4.23.5 / Unity 6000.3.4f1 に対してコンパイルし、翻訳コアの 11 テストを通過しました。MyMemory では中国語・日本語・韓国語・フランス語の応答を確認しています。画面と説明書の多言語化は 0.1.2 の追加機能です。

**ゲーム内での統合動作はまだ検証していません。** 翻訳範囲、レイアウト、日本語・韓国語フォント、第三者の布料 Mod 名は導入後の確認が必要です。開発時に内容パックは導入されていませんでした。

一般的な Unity Text / TextMeshPro の表示経路に対応します。独自描画、画像内の文字、英語以外の原文、ストーリースクリプトの直接書き換えは保証せず、ストーリーファイルは変更しません。専門用語や色の修飾、文法の誤訳は手動で直せます。

## ソースとビルド

プラグインは `src/DressmakerLanguages.cs`、アシスタントは `assistant/` にあります。自分の .NET SDK とゲームのアセンブリでビルドできます。

```sh
python3 src/build.py --game "/path/to/game" --dotnet "/path/to/dotnet"
```
