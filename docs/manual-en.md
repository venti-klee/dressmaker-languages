# Manual installation of Dressmaker Languages

First install [Yuuma ModLoader for Mac](https://www.nexusmods.com/dressmaker/mods/1?tab=files). This archive contains only the independent patch, not the loader, game or fabric mods.

1. Quit the game completely.
2. Extract the manual ZIP. The assistant exports the **saved game language**, current dictionary, cache and manual corrections. Save language changes before exporting. The standalone GitHub manual package defaults to Simplified Chinese and includes only this project's authored basic dictionary.
3. In Steam, right-click the game and choose Manage → Browse local files. Use the game root that already contains `BepInEx`, not `Dressmaker.app/Contents`.
4. Copy `BepInEx/plugins/DressmakerLanguages` from the ZIP into the game's `BepInEx/plugins` folder.
5. Copy `BepInEx/config/DressmakerLanguages` into the game's `BepInEx/config` folder. Create `config` if absent. **Copy these two subfolders individually; never replace the whole BepInEx folder.**
6. For an existing installation, back up the two existing `DressmakerLanguages` folders elsewhere before replacing them. Keep every other plugin and mod.
7. Restart the game.

Expected paths (`LANG` is the exported game language, such as `zh-CN`, `ja` or `fr`):

```text
Game root/
  BepInEx/
    plugins/DressmakerLanguages/DressmakerLanguages.dll
    config/DressmakerLanguages/runtime.json
    config/DressmakerLanguages/known-sources.json
    config/DressmakerLanguages/translations.LANG.json
```

If Finder requests permission, follow the macOS prompt. If copying still fails, check Get Info → Sharing & Permissions on your own game folder for Read & Write access. Do not grant access to everyone. Managed-device restrictions may require an authorized account.

Manual copying does not grant the assistant write access. Scanning, translating and saving the local cache remain available. Until permissions are fixed, export again after new translations or a game-language change, quit the game and copy the update. Runtime collection may fail if the game itself cannot write the configuration folder; the assistant can still scan common JSON display fields in mods. Restarting the assistant checks that both the plugin and configuration are present.

To uninstall, quit the game and remove only the two `DressmakerLanguages` folders. Keep the assistant's `data` folder to retain translations.

A locally exported ZIP may contain your mod names, corrections and translations already present in your game. Keep it for personal use; public distribution should use the basic manual package generated by the project's packaging script.

Version 0.1.2 is an early release; in-game rendering and fonts are not yet verified. Full guides and acknowledgements: [GitHub project](https://github.com/venti-klee/dressmaker-languages).
