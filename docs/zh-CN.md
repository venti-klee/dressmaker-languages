# 针影裁梦多语言补丁 0.1.1

**简体中文** · [English](en.md) · [日本語](ja.md) · [한국어](ko.md) · [Français](fr.md) · [Deutsch](de.md) · [Español](es.md)

这是一个独立制作的 Mac 补丁及本机翻译助手，用来翻译 Yuuma ModLoader 界面和 Mod 物品的显示名称。参考项目：[SallyHCA 的汉化工具](https://www.nexusmods.com/dressmaker/mods/339)、[其公开项目说明](https://github.com/Sally-4869/dressmaker-mods-cn)。本包没有复制该项目的程序、词典或其他资产。

GitHub 的 Download ZIP 是源码快照，不包含已编译的游戏插件或 `.app`。普通玩家请使用 Release 中的 Mac 安装包；源码用户需按本文构建步骤自行编译。项目介绍和发布步骤见 [README](../README.zh-CN.md)。

## 开始使用

1. 先安装 [Yuuma ModLoader 的 Mac 版](https://www.nexusmods.com/dressmaker/mods/1?tab=files)。本机检测到的是 0.7.3；补丁使用本机 Unity / BepInEx 程序集编译。
2. 将本工具解压到一个你可以写入的普通文件夹，保留整个目录结构。需要 Python 3.9 或更新版本；本机已有 Python 3.9.6。基础功能不需要安装 Python 第三方库，也不需要 .NET。
3. 双击 `Start.command`、`启动翻译助手.command`，或双击 `针影裁梦多语言助手.app`。助手会打开本机浏览器页面。命令窗口在运行时请保持打开。
4. 页面顶部的「助手界面语言」会立即切换页面全部文案、动态提示和说明链接，并在当前浏览器记住选择；首次跟随浏览器语言，未支持的语言回退为英语。此设置不改变游戏翻译目标。
5. 确认游戏目录，选择目标语言并点击「保存设置」。默认简体中文。
6. 点击「安装／更新游戏补丁」。它只创建两个专用目录：`BepInEx/plugins/DressmakerLanguages/` 和 `BepInEx/config/DressmakerLanguages/`。
7. 正常启动或重启游戏。打开 Mod Manager / Mod Settings，查看翻译是否生效。首次安装需要重启，之后词典修改和语言切换通常在约 2 秒内刷新已收集的文字。
8. 每次安装新 Mod 后，点击「扫描 Mod 与管理器」。游戏中显示的未知英文也会自动加入队列。

如果想手动安装，只需将本包 `BepInEx/plugins/DressmakerLanguages/` 文件夹放到游戏同名位置；再启动助手、点击「安装／更新游戏补丁」，生成翻译配置。不要使用 Vortex 或 Windows 的 `.exe` 汉化助手。

## 已支持的语言

助手网页与 Markdown 说明均支持中、英、日、韩、法、德、西七种语言。界面语言与游戏翻译目标相互独立。切换界面语言会保留未保存的译文草稿。

| 目标语言 | 内置常用术语 | 额外来源 |
|---|---:|---|
| 简体中文 | 148 条 | 本机游戏官方中文翻译表；免费接口；可选离线模型 |
| 日语 | 148 条 | 本机游戏官方日语翻译表；免费接口；可选离线模型 |
| 韩语 | 148 条 | 免费接口；可选离线模型 |
| 法语 | 148 条 | 免费接口；可选离线模型 |
| 德语 / 西班牙语 | 各 14 条 | 免费接口；可选离线模型，初始词典覆盖较少 |
| 英语 | 保留原文 | 可用于恢复原始显示 |

本机首次导入后中文词典合计 **5,157 条**。游戏官方翻译在本机生成，不包含在可分享的压缩包里。每种语言的缓存独立保存。此工具面向 Mod 的显示文字，不会为游戏本体新增完整韩语、法语等本地化。

## 离线与联网

人工修正优先于内置词典；其余按 **词典 → 已缓存译文 → 完整术语组合 → 已安装的 Argos 离线模型 → 免费联网接口** 处理。

词典和缓存开箱即可离线使用。术语组合要求全部词语都已知；不会将一半中文、一半英文的猜测写入缓存。没有模型且没有联网资源时，陌生词保留英文并留在待翻译列表。

如需断网时也翻译陌生句子：选择语言，点击「下载此语言的离线模型」。首次会联网安装独立 Python 环境及模型，可能耗时较长。完成后点击「退出翻译助手」，再重新打开助手；关闭「允许免费联网补译」并保存，即可完全离线使用。模型需要逐语言下载，来源与可用性取决于 Argos 当前模型索引。模型不随这个包分发，安装流程和游戏内显示尚未完成端到端实测。

默认免费资源是 **MyMemory 的公开查询接口**，无需 API 密钥。它有服务端限额；本工具另设每日 4,500 字节的保守文本预算、请求间隔和失败冷却。单条免费请求最多处理 500 字节，超长条目请用离线模型或人工翻译。可选择自己可使用的 LibreTranslate HTTPS 实例；该选项不保证任意公共实例免费或永久可用。

开启联网补译后，未命中的英文显示文字会发送到你选择的翻译服务。工具不需要上传存档或 Mod 文件。成功结果会缓存；网络断开、接口限额或返回错误时保留原文。没有伪装身份、绕过付费或验证码的逻辑。

## 免费翻译来源

在「免费翻译来源」中选择服务，点击「保存设置」后生效。

- **MyMemory**：默认公开接口，免密钥；有服务端配额。
- **必应网页接口（实验性）**：免密钥，通过公开翻译页面取得临时会话，使用同一会话请求翻译。网页不是稳定的官方开发接口；布局、会话机制或服务限制变化时可能失效。
- **LibreTranslate**：填写自己可使用的 HTTPS 实例。是否免费、是否需要账户，取决于实例；当前接入只支持不要求密钥的实例。

可勾选「所选接口不可用时，改用 MyMemory」，默认关闭。仅在网络或服务不可用时尝试一次备用来源；超长文本、预算不足、格式损坏和地址未填写不会触发备用请求。同一文本可能发送到两个服务，每次尝试都计入每日文本预算。所有联网翻译请求间隔至少 3 秒；连续失败会冷却 5 分钟，保留原文，仍可使用离线词典和缓存。

必应会话只保存在助手内存中；不需要登录，不保存必应账号，不轮换代理，也不绕过验证码。所有来源的成功结果按游戏目标语言缓存，人工修正继续优先。

新增接口的测试覆盖会话解析、中文语言代码映射、异常响应拒绝、离线缓存、备用切换和预算计数。25 项自动测试通过。必应已实际返回中、日、韩、法、德、西译文，并验证缓存离线读取及 `{0}` 占位符保护。测试中也出现连接错误和超时，因此仍标为实验性。

## 修正译文

在助手列表里搜索英文原文，修改译文后点「保存」。这会覆盖同语言的机器翻译及内置译文，并保存到本地。数量占位符、换行和富文本标签必须保留，工具会拒绝破坏格式的译文。

列表最多显示 500 条，使用搜索定位其他条目。「开始补译」会尝试扫描列表中的候选界面文字；自动模式优先处理实际显示的文字和 Mod 物品，避免免费限额被未显示的程序字符串消耗。

## 卸载与数据

点击助手中的「卸载补丁」后重启游戏。专用插件与配置会移入助手 `data/backups/`，词典和缓存保留。原 ModLoader、Mod 包、物品 ID、纹理和存档不由本补丁修改。

- `data/translations.sqlite3`：每语言的缓存与人工译文。
- `data/settings.json`：目标语言、联网设置、游戏路径。
- `data/model-install.log`：离线模型安装日志。
- `.venv/` 和 `models/`：可选离线模型环境与模型。
- 游戏 `BepInEx/config/DressmakerLanguages/pending.jsonl`：游戏收集的未知显示文字。
- 游戏 `BepInEx/LogOutput.log`：查找 `Dressmaker Languages`，可查看加载和字体回退问题。

助手页面只监听本机地址，并使用随机会话令牌保护写入操作。退出助手后，已发布的词典和缓存仍会由游戏补丁读取；自动补译需要助手保持运行。

## 验证情况与限制

- 已针对本机 ModLoader 0.7.3 / BepInEx 5.4.23.5 / Unity 6000.3.4f1 编译成功。
- 11 项核心测试通过：离线行为、语言隔离、人工覆盖、格式保护、失败结果不缓存、免费预算、队列完整性、卸载保留原始文件等。
- 中文、日语、韩语、法语的 MyMemory 请求均已实测返回译文。
- 本机助手页面已打开检查。
- **尚未完成游戏内集成实测；文本覆盖、布局和日韩字体显示仍需安装后验证。**
- 此版本以常见的 Unity Text / TextMeshPro 显示入口接入。自绘文字、图片中的文字、非英语源文本、剧情脚本直接改写等不保证覆盖；本包没有修改剧情文件。
- 机器翻译的面料专业术语、颜色修饰关系和法语语法可能不准确；可人工修正。
- 本机当前未安装任何内容包，所以尚未完成第三方布料包的商店名称实测。

## 源码与构建

游戏插件源码在 `src/DressmakerLanguages.cs`，本机助手源码在 `assistant/`。使用自己安装的 .NET SDK 及游戏程序集重新构建：

```sh
python3 src/build.py --game "/你的游戏目录" --dotnet "/你的dotnet路径"
```
