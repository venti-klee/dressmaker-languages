# Dressmaker 다국어 도우미 0.1.1

[简体中文](zh-CN.md) · [English](en.md) · [日本語](ja.md) · **한국어** · [Français](fr.md) · [Deutsch](de.md) · [Español](es.md)

Yuuma ModLoader 인터페이스와 모드 아이템의 표시 이름을 번역하는 독립 제작 Mac 도우미 및 게임 패치입니다. [SallyHCA 도구](https://www.nexusmods.com/dressmaker/mods/339)와 [공개 프로젝트](https://github.com/Sally-4869/dressmaker-mods-cn)의 기능 설명을 참고했습니다. 해당 프로젝트의 코드, 사전 또는 자산은 포함하지 않습니다.

GitHub Download ZIP은 컴파일된 플러그인과 `.app`이 없는 소스입니다. 플레이어는 Mac Release를 사용하고 소스 사용자는 아래 빌드 절차를 따르세요. 공개 방법은 [README](../README.ko.md)에 있습니다.

## 설치

1. 먼저 [Yuuma ModLoader의 Mac 버전](https://www.nexusmods.com/dressmaker/mods/1?tab=files)을 설치하세요. 이 패치는 이 컴퓨터에 설치된 0.7.3을 참조해 컴파일했습니다.
2. 쓰기 가능한 폴더에 전체 패키지를 압축 해제하세요. Python 3.9 이상이 필요합니다. 기본 기능에는 별도의 Python 라이브러리나 .NET 런타임이 필요하지 않습니다.
3. `Start.command` 또는 `针影裁梦多语言助手.app`을 더블 클릭하면 로컬 브라우저 페이지가 열립니다. 사용하는 동안 명령 창을 열어 두세요.
4. 페이지 상단의 **도우미 표시 언어**를 선택하세요. 화면 문구와 설명서 링크가 즉시 바뀌고 선택은 이 브라우저에 저장됩니다. 게임 번역 언어는 변경하지 않습니다. 처음에는 브라우저 언어를 사용하며 미지원 언어는 영어로 표시합니다.
5. 게임 폴더와 **게임 번역 언어**를 확인하고 **설정 저장**을 클릭하세요. 게임 번역의 기본 언어는 중국어 간체입니다.
6. **게임 패치 설치/업데이트**를 클릭하세요. 전용 폴더 `BepInEx/plugins/DressmakerLanguages/`와 `BepInEx/config/DressmakerLanguages/`만 만들거나 업데이트합니다.
7. 진행 상황을 저장하고 게임을 평소 방법으로 재시작한 뒤 Mod Manager / Mod Settings에서 결과를 확인하세요. 이후 사전 및 언어 변경은 수집된 텍스트에 보통 약 2초 안에 반영됩니다.
8. 새 모드 설치 후 **모드 및 관리자 스캔**을 클릭하세요. 게임 화면에 표시된 미번역 영어도 자동 수집합니다.

수동 설치 시 포함된 `BepInEx/plugins/DressmakerLanguages/` 폴더를 게임의 같은 위치에 복사한 뒤 도우미의 설치 버튼으로 설정을 생성하세요. Windows `.exe` 도우미와 Vortex는 필요하지 않습니다.

## 지원 언어와 범위

도우미 화면과 Markdown 설명서는 중국어, 영어, 일본어, 한국어, 프랑스어, 독일어, 스페인어를 지원합니다. 화면 언어와 게임 번역 언어는 별개입니다.

게임 사전에는 중국어·일본어·한국어·프랑스어의 공통 용어가 각각 148개, 독일어·스페인어가 각각 14개 있습니다. 중국어와 일본어는 사용자가 설치한 게임의 공식 번역표도 가져옵니다. 이 컴퓨터의 중국어 사전은 총 5,157개였지만 게임 버전에 따라 달라집니다. 공식 번역은 로컬에서 생성하며 배포 ZIP에는 포함하지 않습니다. 영어를 선택하면 원문으로 돌아갑니다.

캐시는 번역 언어별로 분리합니다. 이 패치는 모드 표시 텍스트를 번역하며 기본 게임 전체에 한국어나 프랑스어 등의 새 번역을 제공하지는 않습니다.

## 오프라인 및 온라인 번역

수동 수정을 최우선으로 적용하고, 나머지는 **사전 → 캐시 → 모든 단어를 인식하는 용어 조합 → 설치된 Argos 오프라인 모델 → 무료 온라인 서비스** 순서로 처리합니다.

사전과 저장된 번역은 즉시 오프라인으로 사용할 수 있습니다. 이름 조합은 모든 단어가 사전에 있을 때만 번역합니다. 모델과 온라인 서비스가 없으면 모르는 문장은 영어 원문으로 남아 번역 대기 목록에 유지됩니다.

모르는 문장도 오프라인으로 번역하려면 게임 번역 언어를 선택하고 **이 언어의 오프라인 모델 다운로드**를 클릭하세요. 최초 설정 시 독립 Python 환경과 모델을 다운로드하므로 인터넷이 필요하며 시간이 걸릴 수 있습니다. 완료 후 도우미를 종료했다가 다시 열고 온라인 번역을 끈 뒤 설정을 저장하세요. 모델은 언어별로 따로 설치해야 하며 제공 여부는 현재 Argos 모델 목록에 따라 달라집니다. 모델은 패키지에 포함하지 않으며 설치 흐름 전체의 실측 검증은 아직 완료되지 않았습니다.

기본 온라인 서비스는 API 키가 필요 없는 MyMemory 공개 API입니다. 서비스 한도 외에도 도우미는 하루 4,500 UTF-8바이트의 보수적 예산, 요청 간격, 실패 시 대기 시간을 적용합니다. 무료 요청 한 건은 최대 500바이트입니다. 긴 항목은 오프라인 모델이나 수동 번역을 사용하세요. 사용 가능한 LibreTranslate HTTPS 인스턴스를 지정할 수도 있지만 무료 이용이나 지속적인 가용성은 보장하지 않습니다.

온라인 모드에서는 로컬 번역이 없는 영어 표시 텍스트만 선택한 서비스에 전송하며 저장 파일이나 모드 패키지는 보내지 않습니다. 성공한 번역을 캐시하고 연결 실패, 한도 초과, 잘못된 응답 시 원문을 유지합니다. 신원 위장, 결제 우회, CAPTCHA 우회 기능은 없습니다.

## 무료 번역 서비스

번역 서비스를 선택하고 **설정 저장**을 누르세요.

- **MyMemory**: 기본 공개 API로 키가 필요하지 않습니다. 서비스 제공자의 사용 한도가 적용됩니다.
- **Bing 웹 연동 (실험적)**: 키 없이 공개 번역 페이지에서 임시 세션을 받아 번역을 요청합니다. 안정적인 공식 개발자 API가 아니므로 페이지, 세션 방식 또는 사용 제한이 바뀌면 작동하지 않을 수 있습니다.
- **LibreTranslate**: 사용할 수 있는 HTTPS 인스턴스를 입력합니다. 비용과 계정 요구 사항은 인스턴스에 따라 다릅니다. 현재는 키가 필요 없는 인스턴스만 지원합니다.

선택한 서비스를 사용할 수 없을 때 MyMemory를 사용하는 옵션은 기본적으로 꺼져 있습니다. 네트워크 또는 서비스 오류가 나면 대체 서비스를 한 번 시도합니다. 예산 초과, 긴 텍스트, 손상된 서식, 빈 URL에는 대체 요청을 하지 않습니다. 같은 텍스트가 두 서비스에 전송될 수 있고 두 시도 모두 일일 예산에 포함됩니다. 모든 요청은 최소 3초 간격입니다. 실패가 계속되면 5분간 대기하며 원문을 유지합니다. 사전과 캐시는 계속 오프라인으로 쓸 수 있습니다.

Bing 세션은 메모리에만 보관합니다. 로그인, 계정 저장, 프록시 교체, CAPTCHA 우회는 하지 않습니다. 성공한 번역은 게임 대상 언어별로 저장하며 수동 수정이 우선입니다.

세션 파싱, 중국어 코드, 잘못된 응답, 오프라인 캐시, 대체 서비스와 예산을 포함한 자동 테스트 25개를 통과했습니다. Bing에서 중국어, 일본어, 한국어, 프랑스어, 독일어, 스페인어 번역을 실제로 받았고 캐시의 오프라인 재사용과 `{0}` 보호를 확인했습니다. 연결 오류와 시간 초과도 발생했으므로 실험적 옵션을 유지합니다。

## 수정 및 제거

영어 원문을 검색해 번역을 수정한 뒤 **저장**을 클릭하세요. 수동 수정은 같은 언어의 기계 번역과 사전보다 우선합니다. 변수, 줄바꿈, 서식 태그를 유지해야 합니다. 서식이 손상된 번역은 거부합니다. 도우미 언어를 바꿔도 저장하지 않은 번역 초안은 유지합니다.

목록은 최대 500개 항목을 표시하며 나머지는 검색할 수 있습니다. **미번역 텍스트 번역**은 관리자의 후보 문자열도 처리합니다. 자동 모드는 실제 표시된 텍스트와 모드 콘텐츠를 우선해 사용하지 않는 프로그램 문자열에 무료 한도를 소모하지 않도록 합니다.

**패치 제거** 후 게임을 재시작하세요. 전용 플러그인과 설정을 `data/backups/`로 이동하며 번역 데이터는 보존합니다. 기존 로더, 모드, 아이템 ID, 텍스처, 저장 파일은 이 패치가 수정하지 않습니다.

## 로컬 파일

- `data/translations.sqlite3`: 언어별 캐시와 수동 수정.
- `data/settings.json`: 번역 언어, 온라인 옵션, 게임 경로.
- `data/model-install.log`: 오프라인 모델 설치 로그.
- `.venv/`와 `models/`: 선택적 모델 환경과 모델.
- 게임의 `BepInEx/config/DressmakerLanguages/pending.jsonl`: 수집된 미번역 표시 텍스트.
- 게임의 `BepInEx/LogOutput.log`: 로딩이나 폰트 문제는 `Dressmaker Languages`로 검색하세요.

페이지는 이 컴퓨터의 로컬 주소에서만 제공하고 무작위 세션 토큰으로 쓰기 작업을 보호합니다. 도우미 종료 후에도 배포된 사전과 캐시는 게임에서 사용합니다. 자동 번역은 도우미가 실행 중이어야 합니다.

## 검증 및 제한

ModLoader 0.7.3 / BepInEx 5.4.23.5 / Unity 6000.3.4f1을 참조해 컴파일했으며 번역 코어 테스트 11개를 통과했습니다. MyMemory의 중국어·일본어·한국어·프랑스어 응답을 실제 요청으로 확인했습니다. 화면과 설명서의 다국어 지원은 0.1.1에 추가되었습니다.

**게임 안에서의 통합 동작은 아직 검증하지 않았습니다.** 텍스트 범위, 레이아웃, 일본어·한국어 폰트, 외부 원단 모드의 이름은 설치 후 확인해야 합니다. 개발 당시 이 컴퓨터에는 콘텐츠 팩이 설치되어 있지 않았습니다.

일반적인 Unity Text / TextMeshPro 표시 경로에 연결합니다. 사용자 정의 렌더링, 이미지 안의 글자, 영어가 아닌 원문, 스토리 스크립트 직접 수정은 보장하지 않습니다. 스토리 파일은 수정하지 않습니다. 원단 전문 용어, 색 수식 관계 또는 문법의 오역은 수동으로 수정할 수 있습니다.

## 소스 및 빌드

플러그인 소스는 `src/DressmakerLanguages.cs`, 도우미 소스는 `assistant/`에 있습니다. 자신의 .NET SDK와 게임 어셈블리로 빌드하세요.

```sh
python3 src/build.py --game "/path/to/game" --dotnet "/path/to/dotnet"
```

독립 제작 코드와 직접 작성한 사전에는 MIT 라이선스를 적용합니다. 게임 자산이나 참고 프로젝트에 대한 권리를 부여하지 않습니다.
